Sets the icon state of a player: the small status shown with their avatar. The client sends the same packet
type itself whenever its own state changes, so the server only has to forward it to the others in the world.

| Field | Used as |
|---|---|
| `netID` | the player; ignored if they aren't in the world |
| `tileX` | the new icon state: 1 draws `game/busy_chatting.rttex` bobbing over their head, 2 draws `game/busy_brb.rttex`, anything else nothing (avatar draw `0x12fbeec`) |

The values the 5.60 client sends for itself:

| `tileX` | When |
|---|---|
| 0 | a menu or dialog was closed (Community Hub, help, generic dialogs, console input) |
| 2 | a full-screen menu was opened (Community Hub, help, text-input dialogs, captcha) |
| 1 | you are typing: the chat input (`0x1c243e0`, also the console box `0x16840cc`) holds text that doesn't start with `/`, `:`, `;` or `>` (commands aren't shown as chatting). It sends 0 again when the text is empty or a command |

### Decompiled handler

```c
case 0x12:
    if (!self->world) break;
    NetAvatar *p = GetAvatar(pkt->netID);
    if (p) p->iconState = pkt->tileX;          // avatar+0x16c
    break;

// the client's own sender, 0x12eca8c
void NetAvatar::SetIconState(int state)
{
    if (iconState == state) return;
    iconState = state;
    packet hdr = { .type = 0x12, .netID = this->netID, .tileX = state };
    SendGamePacket(&hdr);                      // 0x157ee8c, reliable, no extra data
}
```
