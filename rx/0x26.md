Highlights tiles for 30 seconds. The client stores a main tile (in `netID`) and a list of extra tiles from
the extra data in the world renderer. Every frame until it expires, the renderer (`0x11b7c60`) draws frame 0
of `game/tile_blocks_overlay.rttex` over the main tile and frame 1 over each listed tile. All of them are
tile **indexes**, `y × width + x`, looked up with the same function that 0x1c uses for flags
(`0x1625b8c`). It needs a loaded world.

| Field | Used as |
|---|---|
| `netID` | the main tile's index (`y × width + x`); -1 draws nothing |
| `extraDataLength` | 0 = no list; otherwise the extra data is read |

### Extra data

| Type | Meaning |
|---|---|
| `i32` | count |
| `i32 × count` | more tile indexes, drawn with the second overlay frame |

The list replaces the previous one.

void DrawTileSelection(WorldRenderer *r)
{

    Tile *t = GetTileByIndex(&r->world->tilemap, r->selection.tile);   // 0x1625b8c
