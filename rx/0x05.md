Replaces one tile with the tile record in the extra data: foreground, background, flags and tile extra (door
label, sign text, lock, tree...). The record has the same layout as a tile in the [world data](/guide/world-data).

| Field | Used as |
|---|---|
| `tileX`, `tileY` | the tile; ignored if outside the world |
| `flags` | bit 3 (0x08, `S_EXTENDED`) must be set, or the client sees no extra data and leaves the tile as it is |

### Extra data

One tile record, read by the same code as [SEND_MAP_DATA (0x04)](/packets/04-send-map-data), using the current
world's version:

```text
u16 fg, u16 bg
u16 parent                 lock tile index
u16 flags                  0x01 has extra, 0x02 locked, 0x20 flipped, 0x40 on ...
if flags & 0x02: u16       lock tile index
if flags & 0x01: u8 extra_type + that type's data
if world version > 20 and the item has a component: i32 len, len bytes
```

An fg or bg outside items.dat is cleared and logged (`Illegal item %d in %s`).

### What happens

- If the foreground and background are unchanged, the tile keeps its current damage (hits so far).
- Fish Tank Port (3002) refreshes the renderer's map at that tile. A robot (item type 113) is unregistered.
- Vending Hub - Checkout Counter (9270) or Extractor Dynamo (6142), before or after, refreshes the world renderer.
- For tile extra type 61: if its on/off state changes the renderer's map is refreshed, and if its item changes
  the client runs `OnParticleEffect` with particle 46 at the tile.
- The tile and its 8 neighbours are redrawn.

### Decompiled handler

```c
case 0x05: // SEND_TILE_UPDATE_DATA
    World *w = self->world;
    if (!w) break;
    Tile *tile = GetTile(pkt->tileX, pkt->tileY);
    if (!tile) break;
    u8  damage   = tile->damage;                            // +0x80
    u16 fgBefore = GetFG(tile), bgBefore = tile->bg;
    int  idBefore = -1; bool onBefore = false;
    if (tile->extra && tile->extra->type == 61 && tile->extra->obj) {
        idBefore = tile->extra->obj->id; onBefore = tile->extra->obj->count > 0;
    }
    int offset = 0;
    Tile_Serialize(tile, ExtraData(pkt), &offset, /*write*/ false, w, /*fromServer*/ true, w->version);  // 0x15b0b14
    if (GetFG(tile) == fgBefore && tile->bg == bgBefore) tile->damage = damage;

    if (GetFG(tile) == 3002 /* Fish Tank Port */) RendererMap_Refresh(&self->renderer->map, tile->x, tile->y);
    if (GetItem(GetFG(tile))->type == 113 /* robot */) Robots_Unregister(&self->renderer->robots, tile);
    if (self->renderer && (IsSpecial(fgBefore) || IsSpecial(GetFG(tile))))   // 9270 / 6142
        RefreshRenderer(self->renderer);

    if (tile->extra && tile->extra->type == 61) {
        int id = tile->extra->obj ? tile->extra->obj->id : -1;
        bool on = tile->extra->obj && tile->extra->obj->count > 0;
        if (on != onBefore) RendererMap_Refresh(&self->renderer->map, tile->x, tile->y);
        if (id != idBefore && id != 0 && RendererMap_Find(&self->renderer->map, tile->x, tile->y)) {
            sub_1845684();
            CallFunction(gameRoot, 0, "OnParticleEffect", { 46, position });
        }
    }
    RefreshTileAndNeighbours(&w->tilemap, pkt->tileX, pkt->tileY, true);   // 0x1620a30
    break;

// Tile_Serialize (0x15b0b14), read direction:
    tile->fg = u16(); tile->bg = u16(); tile->parent = u16(); tile->flags = u16();
    if (tile->flags & 0x04) sub_1483fa0(..., tile->fg, 1);
    if (tile->fg >= itemCount) { LogError("Illegal item %d in %s", tile->fg, worldName); SetForeground(tile, 0); }
    if (tile->bg >= itemCount) { LogError("Illegal item %d in %s", tile->bg, worldName); tile->bg = 0; }
    if (tile->flags & 0x02) tile->parent = u16();
    SetForeground(tile, tile->fg, ...);                     // 0x15aef40
    if (tile->flags & 0x01) {
        if (!tile->extra) tile->extra = new TileExtra();
        TileExtra_Serialize(tile->extra, data, &offset, ...);   // 0x15ce080: u8 type + data
        if (!tile->extra->valid) { delete tile->extra; tile->extra = NULL; tile->flags &= ~0x01; }
    }
    if (version > 20) TileComponent_Serialize(tile, data, &offset, ...);   // 0x15b1144: i32 len + bytes
```
