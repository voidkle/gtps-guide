0x18 APP_CHECK_RESPONSE ​

GAME_PACKET (4) client → server inferred

Header fields used ​

Offsets are from the game packet header. Fields not listed are 0.

FieldMeaning
netID1-based position of the last listed app that is installed, or -1 if none is
itemIDsum of HashString(name) over the listed apps that are not installed

Official client ​

Received: ignored (falls to the switch's default).

Sent: Sent once after OnSuperMainStartAcceptLogon… when its argument 4 is a string: a space-separated list of Android package names the client checks for.
